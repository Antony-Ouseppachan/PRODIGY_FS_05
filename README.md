# 📲 Snappin

Snappin is a minimal and interactive social media platform where users can create profiles, share posts, and engage through likes and comments. Built for smooth user experience and real-time interaction.

---

## 🛠 Features

- User authentication (Sign up / Login)
- Create, view, and delete posts
- Like/unlike posts (1 like per user per post)
- View like counts dynamically
- Comment on posts
- Responsive and intuitive UI

---

## 🚀 Technologies Used

- **Frontend**: HTML, CSS, JavaScript, EJS
- **Backend**: Node.js, Express.js
- **Database**: MySQL
- **Session Management**: express-session
- **Icons/UI**: MDBootstrap, Font Awesome

---

## 📂 Project Structure


## 🧪 Setup Instructions

1. **Clone the repository**
   ```bash
   git clone https://github.com/Antony-Ouseppachan/PRODIGY_FS_05.git
   cd snappin
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Configure the database**
   - Create a MySQL database `snappin_db`
   - Import the SQL schema
   - Update your `db.js` with credentials

4. **Start the server**
   ```bash
   node server.js
   ```

5. **Visit in browser**
   ```
   http://localhost:5000
   ```
